✅ Step-by-Step: Use ChatGPT via OpenAI API in Terminal (CMD)
✅ Prerequisites:
A working OpenAI API key – get it from https://platform.openai.com/account/api-keys

Python 3 installed

Internet connection

🔧 Step 1: Install OpenAI Python Package

pip install openai
🔧 Step 2: Export Your OpenAI API Key
Replace your-api-key-here with your real key:


export OPENAI_API_KEY="your-api-key-here"
To make it permanent, add that line to your ~/.bashrc and run source ~/.bashrc.
